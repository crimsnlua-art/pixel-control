# 직접 해 주실 일

## A. 픽셀 0단계 확인 (앱 없이, 10~20분)
목적: 갤럭시에서 찍은 사진이 픽셀을 거치면 정말 무료로 올라가는지, "기기 공간 확보"가 어떻게 지우는지 확인.

준비
1. 픽셀1을 와이파이에 연결, 주력 폰과 **같은 구글 계정**으로 구글 포토 로그인.
2. 픽셀 설정 > 저장용량 > **스마트 저장용량 끄기**.
3. 구글 포토(픽셀) > 프로필 > 포토 설정 > 백업 > **백업 화질이 "원본 화질"**인지 확인.
4. 지금 계정 사용량 기록: https://one.google.com/storage (또는 포토 설정 > 백업 > 저장용량) — 숫자를 적어 둠.

시험
5. 주력 폰에서 사진 5장(그중 1장은 위치 켜고) + 짧은 영상 1개를 찍음. 주력 폰 구글 포토는 **백업 꺼 둔 상태**여야 함(켜져 있으면 주력 폰이 먼저 올려서 용량 차감).
6. USB 케이블이나 파일 공유로 그 파일들을 픽셀의 `Pictures/PixelRelay` 폴더에 복사(폴더 없으면 만들기).
   - PC 를 거치면: 주력 폰 → PC → 픽셀(파일 전송 모드).
7. 픽셀 구글 포토 > 라이브러리 > 기기의 사진 > PixelRelay 폴더 > **백업 켜기**. 업로드 끝날 때까지 기다림(포토 상단에 "백업 완료").
8. PC 브라우저 photos.google.com 에서 그 사진 하나 열기 > 정보(i) > 크기·화질이 원본인지, 촬영 날짜·위치가 맞는지.
9. 다시 계정 사용량 확인 → 4번 숫자와 같으면 **무료 성공**.
10. 픽셀 구글 포토 > 프로필 > **기기 저장공간 확보** 실행 → 방금 올린 파일들이 픽셀 `Pictures/PixelRelay` 에서 사라지는지(파일 관리자로 확인). 최근 파일이라 안 지워지면 그것도 알려 주세요.

알려 주실 것: 9번(용량 늘었나), 10번(지워졌나), 8번(위치·날짜 맞나).

## B. 구글 로그인 설정 (드라이브 중계용, 계정 주인만 가능, 15분)
앱 구현이 끝나면 "서명 지문(SHA-1)"을 드릴 테니 그때 마지막 단계만 하면 됩니다. 앞부분은 미리 해도 됩니다.

1. https://console.cloud.google.com 접속 → 위쪽 프로젝트 선택 > **새 프로젝트** → 이름 `pixelrelay` → 만들기.
2. 왼쪽 메뉴 > API 및 서비스 > 라이브러리 → "Google Drive API" 검색 → **사용**.
3. API 및 서비스 > OAuth 동의 화면(Google 인증 플랫폼) → 시작하기:
   - 앱 이름 `픽셀중계`, 지원 이메일 = 본인, 대상 = **외부**, 연락처 이메일 = 본인 → 만들기.
   - 데이터 액세스(범위) > 범위 추가 → `.../auth/drive.appdata` 선택 → 저장.
   - 대상 > 앱 게시(프로덕션으로 푸시) — 이 범위는 민감 범위가 아니라서 검수 없이 될 것으로 봄(구현 쪽에서 확인 중). 테스트 상태로 두면 7일마다 로그인이 풀릴 수 있음.
4. (서명 지문 받은 뒤) 클라이언트 > 클라이언트 만들기 → 유형 **Android** → 패키지 이름 `com.pixelrelay`, SHA-1 인증서 지문 = 드린 값 → 만들기.
   - 만든 뒤 따로 복사해 올 값은 없습니다(앱은 패키지+서명으로 자동 연결).
