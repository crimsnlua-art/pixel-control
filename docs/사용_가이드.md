# 픽셀중계 사용 가이드 (v0.1.0)

앱을 처음 켜면 **설정 마법사**가 자동으로 뜨고 단계마다 안내·바로가기 버튼이 있습니다. 이 문서는 순서 요약입니다.
**픽셀을 먼저** 설정하세요(마지막에 픽셀의 짝짓기 코드가 필요).

## 1. 픽셀1 (역할: 받기)
1. 앱 열기 → **"이 기기를 받기로 사용"**
2. 설정 마법사(7단계)
   1. **권한** — 저장소(파일 쓰기)·알림 허용 (자동 체크)
   2. **배터리 최적화 제외** — 버튼 → "제한 없음/최적화 안 함" (자동 체크)
   3. **화면 잠금 '없음'** — 버튼 → 설정 > 보안 > 화면 잠금 > 없음 → 돌아와 "했어요" 체크
   4. **스마트 저장용량 끄기** — 버튼 → 설정 > 저장용량 > 스마트 저장용량 끄기 → "했어요"
   5. **구글 포토에서 PixelRelay 폴더 백업 켜기** — 버튼으로 포토 열기 → 라이브러리 > 기기 폴더 > PixelRelay > 백업 켜기(원본 화질 확인) → "했어요"
   6. **구글 계정 연결** — 주력 폰과 같은 계정. *구글 등록 전에는 "앱 등록이 아직 안 됨" 이 나오며, 건너뛰어도 집 와이파이 전송은 됩니다.*
   7. **짝짓기** — '짝짓기' 탭에 6자리 코드가 보임(5분 유효, 지나면 "새 코드 만들기")
3. 픽셀은 집 와이파이에 연결해 두고 충전기에 꽂아 둡니다. 상단 알림에 서비스가 상시 표시됩니다.

## 2. 주력 폰 (역할: 보내기)
1. 앱 열기 → **"이 기기를 보내기로 사용"**
2. 설정 마법사(5단계)
   1. **권한** — 사진·영상은 반드시 **"전체 허용"**(일부만 허용하면 새 사진 감지가 안 됨), 사진 위치 정보, 알림 (자동 체크)
   2. **배터리 최적화 제외** — 삼성은 '절전 예외 앱'에도 추가
   3. **이 폰의 구글 포토 백업 끄기** — 주력 폰이 먼저 올리면 용량이 차감됨 → 포토 > 프로필 > 포토 설정 > 백업 끄기 → "했어요"
   4. **구글 계정 연결** — 픽셀과 같은 계정 (등록 전이면 건너뜀)
   5. **픽셀 짝짓기** — '연결' 탭에 픽셀 화면의 6자리 코드 입력(픽셀 IP 는 비워 두면 자동 찾기, 같은 와이파이여야 함) → "짝짓기 성공"

## 3. 쓰는 법
- 그냥 사진·영상을 찍으면 됩니다. 집 와이파이에서는 자동으로 픽셀로 갑니다(확인은 몇 분~15분 간격).
- **주력 폰 '홈' 탭**: 상태별 개수(대기·전송 중·픽셀 받음·포토 확인), 픽셀 남은 공간·배터리·온도·충전·마지막 소식, 경고, **"지금 보내기"**.
- **'파일' 탭**: 파일별 상태.
- **픽셀 공간 정리**: 픽셀 앱 '상태' 탭의 **"포토 공간 확보 열기"** 를 눌러 구글 포토의 '기기 저장공간 확보'를 실행 → 1시간 안에 사라진 파일이 "포토 확인"으로 바뀝니다. (반드시 이 버튼으로 열어야 확인으로 인정됨)
- **원인 불명**: 버튼 없이 사라진 파일. 포토 웹에서 원본이 있는지 보고 "포토 확인됨으로 확정" 또는 주력 폰에서 "다시 보내기".
- 경고(고온·공간 부족·포토 멈춤·충전기 빼기 권장 등)는 주력 폰 알림으로 옵니다.

## 4. 처음 한 번 해 볼 것 (구글 등록 뒤)
- 주력 폰 '설정' 탭 → **"무료 업로드 확인 시험"** → 사진 3장 고르기 → 픽셀에서 포토 백업 끝나면 "포토 백업 완료됐어요" → 앱이 계정 용량을 재서 "무료 확인 / 용량 차감됨" 을 알려 줌 → 이어서 공간 확보 시험.

## 5. 아직 안 되는 것
- 밖(모바일 데이터)에서 드라이브 경유 전송·원격 상태: 구글 등록 뒤 사용 가능.
- 스마트 플러그 충전 끄기/켜기: 플러그 구매 후 2단계.
